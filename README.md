# Descripción del Proyecto
Nuestro proyecto Food Flash es algo como una compra en linea de comida pero enfocado en la universidad, donde estudiantes, docentes y el personal que desee usarlo podrán pedir comida del comedor o chalet que quiera, esto ayudara a ahorrarse tiempo de espera y largas filas, el usuario solo pedira lo que desea comer y luego irá a retirar su pedido
